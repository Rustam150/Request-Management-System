# Система заявок в техподдержку

Веб-приложение для создания и управления заявками в техподдержку.

**Автор:** Цицкиев Рустам Бесланович, группа 4Р2-9,23  
**Республика:** Ингушетия  
**Дата:** 06.10.2026

## Что это?

Сайт где можно создавать заявки в техподдержку (например "не работает компьютер"), смотреть список своих заявок, редактировать их и менять статус (новая → в работе → решена).

## Технологии

**Backend:**
- Node.js + Express - сервер
- SQLite - база данных
- JWT - авторизация по токенам
- bcrypt - шифрование паролей

**Frontend:**
- React - интерфейс
- Vite - сборка проекта
- React Router - переходы между страницами
- Axios - запросы к серверу

## Как запустить

### 1. Запуск сервера (backend)

Открываем терминал в папке проекта:

```bash
cd backend
npm install
node server.js
```

Сервер запустится на http://localhost:5000

### 2. Запуск сайта (frontend)

Открываем НОВЫЙ терминал:

```bash
cd frontend
npm install
npm run dev
```

Сайт откроется на http://localhost:3000

### 3. Как пользоваться

1. Открой в браузере http://localhost:3000
2. Зарегистрируйся (введи ФИО, группу, логин, пароль)
3. Создавай заявки, редактируй их, меняй статус

## API (что умеет сервер)

**Без авторизации:**
- `POST /api/register` - регистрация
- `POST /api/login` - вход

**С авторизацией (нужен токен):**
- `GET /api/requests` - получить все мои заявки
- `GET /api/requests/:id` - получить одну заявку
- `POST /api/requests` - создать заявку
- `PUT /api/requests/:id` - изменить заявку
- `DELETE /api/requests/:id` - удалить заявку

## Если что-то не работает

1. **База данных не создается** - запусти `node test-db.js` в папке backend
2. **Ошибка регистрации** - проверь что backend запущен на порту 5000
3. **Страница не открывается** - проверь что frontend запущен на порту 3000
4. **Порт занят** - закрой другие Node.js процессы
